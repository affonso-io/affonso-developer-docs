---
title: "Create Campaign"
api: "POST https://api.affonso.io/v1/program/campaigns"
description: "Create a draft program campaign, including retainer rewards"
---

Create a draft campaign for your team. Status is always `DRAFT` on create. Requires `write:program`.

Reward type rules:

- `flat_rate` requires `reward_amount`
- `range` requires `reward_amount_min` and `reward_amount_max` (min >= 0.01, max >= min)
- `custom` sets no amounts
- `retainer` requires `reward_amount`, `retainer_interval`, and either `retainer_day_of_month` (monthly) or `retainer_weekday` (weekly). For retainer, omitted `application_required` is set to `true`; sending `false` returns `VALIDATION_ERROR` ("Retainer campaigns require an application"). Ignores `max_budget` (stored as `null`)

## Body Parameters

<ParamField body="name" type="string" required>
  Campaign title. Must be between 1 and 255 characters.
</ParamField>

<ParamField body="reward_type" type="string" required>
  Reward type. Valid values: `flat_rate`, `custom`, `range`, `retainer`.
</ParamField>

<ParamField body="start_date" type="string" required>
  Campaign start datetime (ISO 8601).
</ParamField>

<ParamField body="description" type="string | null">
  Campaign description. Maximum 10,000 characters. Set to `null` or omit for none.
</ParamField>

<ParamField body="reward_amount" type="number | null">
  Fixed reward amount in program currency. Required for `flat_rate` and `retainer`. Minimum 0.01. Null for `custom` and `range`.
</ParamField>

<ParamField body="reward_amount_min" type="number | null">
  Range minimum. Required when `reward_type` is `range`. Minimum 0.01.
</ParamField>

<ParamField body="reward_amount_max" type="number | null">
  Range maximum. Required when `reward_type` is `range`. Must be greater than or equal to `reward_amount_min`.
</ParamField>

<ParamField body="max_budget" type="number | null">
  Owner-only cap on approved reward spend. Null or omit for no cap. Partners never see this. Ignored on retainer (stored as `null`).
</ParamField>

<ParamField body="retainer_interval" type="string | null">
  Required when `reward_type` is `retainer`. Valid values: `monthly`, `weekly`.
</ParamField>

<ParamField body="retainer_day_of_month" type="integer | string | null">
  Monthly retainer day. Valid values: integer `1`-`28`, or `"last"`. Required when `retainer_interval` is `monthly`.
</ParamField>

<ParamField body="retainer_weekday" type="string | null">
  Weekly retainer weekday. Valid values: `monday`, `tuesday`, `wednesday`, `thursday`, `friday`, `saturday`, `sunday`. Required when `retainer_interval` is `weekly`.
</ParamField>

<ParamField body="end_date" type="string | null">
  Campaign end datetime (ISO 8601). Set to `null` or omit for open-ended.
</ParamField>

<ParamField body="application_required" type="boolean">
  When true, affiliates must apply and be accepted before submitting proof. For retainer, omitted `application_required` is set to `true`; sending `false` returns `VALIDATION_ERROR` ("Retainer campaigns require an application").
</ParamField>

<ParamField body="application_prompt" type="string | null">
  Question shown to affiliates when they apply. Maximum 10,000 characters.
</ParamField>

<ParamField body="max_submissions_per_user" type="integer | null">
  Maximum approved submissions per affiliate. Integer >= 1, or `null` for no limit.
</ParamField>

## Notes

- Requires `write:program`.
- Retainer campaigns always require applications. For retainer, omitted `application_required` is set to `true`; sending `false` returns `VALIDATION_ERROR` ("Retainer campaigns require an application").
- `max_budget` is ignored for retainer and stored as `null`.
- Campaign IDs are encoded, same as marketplace campaign IDs.
