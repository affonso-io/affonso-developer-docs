---
title: "Get Campaign"
api: "GET https://api.affonso.io/v1/program/campaigns/{id}"
description: "Get one of your team's program campaigns"
---

Get one campaign owned by your team. Requires `read:program`. Foreign-team campaign IDs return 404.

The same data is available through the [`affonso_get_campaign`](/mcp/tools/campaigns) MCP tool.

## Path Parameters

<ParamField path="id" type="string" required>
  Encoded campaign id
</ParamField>

## Response

Returns the campaign object. Same structure as [Create Campaign](/api/endpoint/campaigns/create).

<ResponseField name="success" type="boolean">
  Always `true` for successful responses
</ResponseField>

<ResponseField name="data" type="object">
  The campaign. Fields match the campaign object in [List Campaigns](/api/endpoint/campaigns/list).
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.affonso.io/v1/program/campaigns/cmlaunch01camp0001" \
  -H "Authorization: Bearer sk_live_your_api_key"
```

## Notes

- Requires `read:program`.
- A campaign that does not exist or belongs to another team returns `NOT_FOUND` (HTTP 404).
