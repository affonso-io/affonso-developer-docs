---
title: "List Retainer Periods"
api: "GET https://api.affonso.io/v1/program/campaigns/{id}/retainer-periods"
description: "List open retainer periods waiting for manual approval"
---

List retainer periods whose earning is `PENDING_MANUAL_APPROVAL`. Requires `read:affiliates`. Foreign-team campaign IDs return 404.

## Path Parameters

<ParamField path="id" type="string" required>
  Encoded campaign id
</ParamField>

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination. Must be a positive integer.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Number of results per page. Maximum value is 200. Default is 50.
</ParamField>

## Response

Paginated list of open retainer periods.

<ResponseField name="success" type="boolean">
  Always `true` for successful responses
</ResponseField>

<ResponseField name="data" type="array">
  Array of retainer period objects.

<Expandable title="Period Object Properties">
<ResponseField name="id" type="string">
  Encoded period id
</ResponseField>

<ResponseField name="campaign_id" type="string">
  Encoded campaign id
</ResponseField>

<ResponseField name="application_id" type="string">
  Encoded application id
</ResponseField>

<ResponseField name="affiliate_id" type="string">
  Affiliate id
</ResponseField>

<ResponseField name="period_start" type="string">
  ISO 8601 start of the retainer period
</ResponseField>

<ResponseField name="amount" type="number | null">
  Period earning amount
</ResponseField>

<ResponseField name="earning_id" type="string | null">
  Encoded affiliate earning id
</ResponseField>

<ResponseField name="earning_status" type="string | null">
  Earning status. Listed periods are `PENDING_MANUAL_APPROVAL`.
</ResponseField>

<ResponseField name="condition" type="string | null">
  Retainer condition text copied from the application, or `null`
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata: `page`, `limit`, `total`, `total_pages`, `has_next_page`, `has_prev_page`.
</ResponseField>

## Notes

- Requires `read:affiliates`.
- Only periods with earnings in `PENDING_MANUAL_APPROVAL` are returned.
- Approve with [Approve Retainer Period](/api/endpoint/campaigns/approve-retainer-period) or reject with [Reject Retainer Period](/api/endpoint/campaigns/reject-retainer-period).
