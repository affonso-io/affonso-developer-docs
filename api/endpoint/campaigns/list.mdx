---
title: "List Campaigns"
api: "GET https://api.affonso.io/v1/program/campaigns"
description: "List your team's program campaigns"
---

List the campaigns owned by your team, newest `start_date` first. Requires `read:program`.

The same data is available through the [`affonso_list_campaigns`](/mcp/tools/campaigns) MCP tool.

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination. Must be a positive integer.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Number of results per page. Maximum value is 200. Default is 50.
</ParamField>

<ParamField query="status" type="string">
  Filter by campaign status. Valid values: `DRAFT`, `SCHEDULED`, `ACTIVE`, `ENDED`, `ARCHIVED`.
</ParamField>

## Response

Paginated list of campaigns.

<ResponseField name="success" type="boolean">
  Always `true` for successful responses
</ResponseField>

<ResponseField name="data" type="array">
  Array of campaign objects.

<Expandable title="Campaign Object Properties">
<ResponseField name="id" type="string">
  Encoded campaign id
</ResponseField>

<ResponseField name="name" type="string">
  Campaign title
</ResponseField>

<ResponseField name="description" type="string | null">
  Campaign description
</ResponseField>

<ResponseField name="kind" type="string">
  Always `"submission"`
</ResponseField>

<ResponseField name="status" type="string">
  Campaign status. Valid values: `DRAFT`, `SCHEDULED`, `ACTIVE`, `ENDED`, `ARCHIVED`.
</ResponseField>

<ResponseField name="reward_type" type="string">
  `flat_rate`, `custom`, `range`, or `retainer`
</ResponseField>

<ResponseField name="reward_amount" type="number | null">
  Fixed reward amount
</ResponseField>

<ResponseField name="reward_amount_min" type="number | null">
  Range minimum
</ResponseField>

<ResponseField name="reward_amount_max" type="number | null">

  Owner-only spend cap. Null means no cap. Always null on retainer.

  `monthly` or `weekly` for retainer campaigns, otherwise `null`

  ISO 8601 timestamp of the last retainer schedule change, or `null`
</ResponseField>

<ResponseField name="retainer_resumed_at" type="string | null">
  ISO 8601 timestamp set only when a retainer campaign moves from ENDED or ARCHIVED to ACTIVE, or `null`

<ResponseField name="start_date" type="string">
  ISO 8601 start datetime
</ResponseField>

<ResponseField name="end_date" type="string | null">

<ResponseField name="application_required" type="boolean">

</ResponseField>

<ResponseField name="application_prompt" type="string | null">
  Application question text
</ResponseField>

<ResponseField name="max_submissions_per_user" type="integer | null">
  Per-affiliate submission cap
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 update timestamp
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata: `page`, `limit`, `total`, `total_pages`, `has_next_page`, `has_prev_page`.
</ResponseField>

## Notes

- Requires `read:program`.
- Campaigns are sorted by `start_date` descending, then by id.
- An unknown `status` value returns `VALIDATION_ERROR` (HTTP 400).
- Get a single campaign with [Get Campaign](/api/endpoint/campaigns/get).
