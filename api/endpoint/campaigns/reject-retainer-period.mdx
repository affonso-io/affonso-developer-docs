---
title: "Reject Retainer Period"
api: "POST https://api.affonso.io/v1/program/campaigns/{id}/retainer-periods/{periodId}/reject"
description: "Reject a PENDING_MANUAL_APPROVAL retainer period earning"
---

Reject a retainer period earning that is `PENDING_MANUAL_APPROVAL`. Writes `DECLINED` on the earning. Requires `write:affiliates`. Foreign-team IDs return 404.

## Path Parameters

<ParamField path="id" type="string" required>
  Encoded campaign id
</ParamField>

<ParamField path="periodId" type="string" required>
  Encoded retainer period id
</ParamField>

## Response

Returns the period object with updated `earning_status`.

<ResponseField name="success" type="boolean">
  Always `true` for successful responses
</ResponseField>

<ResponseField name="data" type="object">
  The retainer period. Fields match [List Retainer Periods](/api/endpoint/campaigns/list-retainer-periods).
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.affonso.io/v1/program/campaigns/cmretainer01camp0001/retainer-periods/cmperiod01retainer001/reject" \
  -H "Authorization: Bearer sk_live_your_api_key"
```
</RequestExample>

## Notes

- Requires `write:affiliates`.
- No request body.
- Periods that are not `PENDING_MANUAL_APPROVAL` return a conflict.
