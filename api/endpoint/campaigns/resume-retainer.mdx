---
title: "Resume Partner Retainer"
api: "POST https://api.affonso.io/v1/program/campaigns/{id}/applications/{applicationId}/resume-retainer"
description: "Resume an ended partner retainer"
---

Resume an ended partner retainer on an accepted application. Clears `retainer_ended_at` and sets `retainer_resumed_at`. Requires `write:affiliates`. Foreign-team IDs return 404.

## Path Parameters

<ParamField path="id" type="string" required>
  Encoded campaign id
</ParamField>

<ParamField path="applicationId" type="string" required>
  Encoded application id
</ParamField>

## Response

Returns the application with the retainer resumed. Same structure as [Accept Campaign Application](/api/endpoint/campaigns/accept-application).

<RequestExample>
```bash cURL
curl -X POST "https://api.affonso.io/v1/program/campaigns/cmretainer01camp0001/applications/cmapp01retainer0001/resume-retainer" \
  -H "Authorization: Bearer sk_live_your_api_key"
```
</RequestExample>

## Notes

- Requires `write:affiliates`.
- No request body.
- The application must already be an ended retainer. Otherwise the API returns a conflict.
