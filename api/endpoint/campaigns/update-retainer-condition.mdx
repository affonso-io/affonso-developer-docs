---
title: "Update Retainer Condition"
api: "PATCH https://api.affonso.io/v1/program/campaigns/{id}/applications/{applicationId}/condition"
description: "Update the retainer condition on an accepted application"
---

Change the retainer condition on an accepted application. Requires `write:affiliates`. Foreign-team IDs return 404.

## Path Parameters

<ParamField path="id" type="string" required>
  Encoded campaign id
</ParamField>

<ParamField path="applicationId" type="string" required>
  Encoded application id
</ParamField>

## Body Parameters

<ParamField body="has_condition" type="boolean" required>
  `true` to keep or set a condition. `false` clears the condition text.
</ParamField>

<ParamField body="condition" type="string | null">
  Condition text. Required when `has_condition` is true. Maximum 2000 characters. Cleared when `has_condition` is false.
</ParamField>

## Response

Returns the updated application object. Same structure as [Accept Campaign Application](/api/endpoint/campaigns/accept-application).

<RequestExample>
```bash cURL
curl -X PATCH "https://api.affonso.io/v1/program/campaigns/cmretainer01camp0001/applications/cmapp01retainer0001/condition" \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "has_condition": true,
    "condition": "Post at least 3 Shorts per week mentioning our product"
  }'
```

```bash cURL (clear condition)
curl -X PATCH "https://api.affonso.io/v1/program/campaigns/cmretainer01camp0001/applications/cmapp01retainer0001/condition" \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "has_condition": false
  }'
```
</RequestExample>

## Notes

- Requires `write:affiliates`.
- Only accepted retainer applications can be updated. Non-retainer or non-accepted applications return an error.
