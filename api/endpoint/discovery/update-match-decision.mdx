---
title: "Update Discovery Match Decision"
api: "PATCH https://api.affonso.io/v1/discovery/matches/{id}"
description: "Set or clear the customer accept/reject decision on a Discovery match"
---

Set `accepted`, `rejected`, or `none` on a Discovery match. Requires the `write:discovery` permission.

<Info>
  `none` clears the decision and is not the same as `rejected`. The update is idempotent. It does not change fit score or start a new search.
</Info>

A match owned by another team returns `403` with code `FORBIDDEN`. A missing match returns `404` with code `NOT_FOUND`. Extra body properties are rejected.

## Path Parameters

<ParamField path="id" type="string" required>
  Discovery match ID
</ParamField>

## Body Parameters

The request body is strict. Only `decision` is accepted.

<ParamField body="decision" type="string" required>
  Customer review decision. Valid values: `accepted`, `rejected`, `none`. Setting `none` clears the decision.
</ParamField>

## Response

The response wraps the updated `DiscoveryMatchReview` object.

<ResponseField name="success" type="boolean">
  Always `true` for successful responses
</ResponseField>

<ResponseField name="data" type="object">
  Updated Discovery match review decision.

<Expandable title="Data Object Properties">
<ResponseField name="id" type="string">
  Discovery match ID
</ResponseField>

<ResponseField name="agent_id" type="string | null">
  Discovery agent that produced the match. Can be `null`.
</ResponseField>

<ResponseField name="prospect_id" type="string">
  Prospect ID linked to the match
</ResponseField>

<ResponseField name="decision" type="string">
  Customer review decision. Valid values: `accepted`, `rejected`, `none`.
</ResponseField>

<ResponseField name="decided_at" type="string | null">
  ISO 8601 timestamp of when the decision was set. `null` when `decision` is `none`.
</ResponseField>
</Expandable>
</ResponseField>

<RequestExample>
```bash cURL Accept
curl -X PATCH "https://api.affonso.io/v1/discovery/matches/cmmatch123abc" \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "decision": "accepted"
  }'
```

```bash cURL Clear
curl -X PATCH "https://api.affonso.io/v1/discovery/matches/cmmatch123abc" \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "decision": "none"
  }'
```
</RequestExample>
