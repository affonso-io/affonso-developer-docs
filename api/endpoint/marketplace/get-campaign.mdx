---
title: "Get Marketplace Campaign"
api: "GET https://api.affonso.io/v1/marketplace/campaigns/{id}"
description: "Get a live marketplace campaign teaser or an approved partner's full brief"
---

Retrieve a live marketplace campaign. Without `affiliate_id`, this endpoint is public, ignores the `Authorization` header (including invalid keys), and returns a teaser with `details: null`. Supply `affiliate_id` and an API key to request the full brief for an eligible partner of your team.

<Info>
  The team routes under `/v1/program/campaigns`, [List Campaigns](/api/endpoint/campaigns/list) and [Get Campaign](/api/endpoint/campaigns/get), require an API key with `read:program`. They return only your team's campaigns in any status, including drafts, with owner fields such as `status`, `max_budget` and retainer settings. Marketplace routes show the partner view: only live campaigns from marketplace-listed programs across any team, public teasers without authentication, no `max_budget`, and hidden owner settings. The full brief (`details`) is available only for an approved partner of your team through `affiliate_id` and an API key with `read:affiliates`.
</Info>

## Path Parameters

<ParamField path="id" type="string" required>
  Encoded campaign id
</ParamField>

## Query Parameters

<ParamField query="affiliate_id" type="string">
  Id of a partner on your team. Requires `Authorization: Bearer sk_live_your_api_key` and `read:affiliates`, also satisfied by `write:affiliates`, `delete:affiliates`, or `read`.
</ParamField>

## Notes

- Only `ACTIVE` campaigns whose `start_date` is at or before now and whose `end_date` is `null` or at or after now are visible. Their program must have joined the marketplace, be `ACTIVE`, and have an access mode other than `invite`.
- Public marketplace requests have an IP rate limit of 60 requests per window. Rate limit headers are `X-RateLimit-Limit`, `X-RateLimit-Remaining` and `X-RateLimit-Reset`. Authenticated requests also have the normal API key rate limit.
- Responses use `Cache-Control: no-store` because campaign windows are time-sensitive.
- Campaign visibility is checked before any partner lookup. Unknown, invisible or undecodable campaign ids return `NOT_FOUND` (HTTP 404), with the message "Campaign not found".
- With `affiliate_id` but no `Authorization` header, the response is `UNAUTHORIZED` (HTTP 401), with the message "Authentication required". A key without the required permission returns `INSUFFICIENT_PERMISSIONS` (HTTP 403).
- A partner not on your team returns `AFFILIATE_NOT_FOUND` (HTTP 404), with the message "Affiliate not found or does not belong to your team" and field `affiliate_id`.
- There is no marketplace join endpoint. Partners join through the hosted portal, for example using a portal token from `POST /v1/affiliates/{id}/portal-token`. Apply on a partner's behalf using the team route [Apply to Campaign](/api/endpoint/campaigns/apply).
- `max_budget` is never returned on marketplace routes.
- A server error returns `INTERNAL_ERROR` (HTTP 500), with the message "Failed to fetch campaign".
