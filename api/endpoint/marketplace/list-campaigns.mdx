---
title: "List Marketplace Campaigns"
api: "GET https://api.affonso.io/v1/marketplace/campaigns"
description: "List public teasers for live marketplace campaigns"
---

List live marketplace campaign teasers, ordered by `start_date` descending. This endpoint is public and does not require authentication. The `Authorization` header is ignored, including leftover or invalid API keys.

<Info>
  The team routes under `/v1/program/campaigns`, [List Campaigns](/api/endpoint/campaigns/list) and [Get Campaign](/api/endpoint/campaigns/get), require an API key with `read:program`. They return only your team's campaigns in any status, including drafts, with owner fields such as `status`, `max_budget` and retainer settings. Marketplace routes show the partner view: only live campaigns from marketplace-listed programs across any team, public teasers without authentication, no `max_budget`, and hidden owner settings. The full brief (`details`) is available only for an approved partner of your team through `affiliate_id` and an API key with `read:affiliates`.
</Info>

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination. Minimum 1.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Number of results per page. Minimum 1, maximum 200.
</ParamField>

<ParamField query="marketplace_id" type="string">
  Filter by an encoded marketplace program id from [List Marketplace Programs](/api/endpoint/marketplace/list) or [Get Marketplace Program](/api/endpoint/marketplace/get).
</ParamField>

## Notes

- Only `ACTIVE` campaigns whose `start_date` is at or before now and whose `end_date` is `null` or at or after now are visible. Their program must have joined the marketplace, be `ACTIVE`, and have an access mode other than `invite`.
- Public marketplace requests have an IP rate limit of 60 requests per window. Rate limit headers are `X-RateLimit-Limit`, `X-RateLimit-Remaining` and `X-RateLimit-Reset`. Authenticated requests also have the normal API key rate limit.
- Responses use `Cache-Control: no-store` because campaign windows are time-sensitive.
- Only teasers are returned. `max_budget` is never returned on marketplace routes.
- Invalid `page` or `limit` values return `VALIDATION_ERROR` (HTTP 400), with the message "Invalid query parameters" and `details`.
- An invalid `marketplace_id` returns `VALIDATION_ERROR` (HTTP 400), with the message "Invalid marketplace program ID" and field `marketplace_id`.
- A server error returns `INTERNAL_ERROR` (HTTP 500), with the message "Failed to fetch campaigns".
