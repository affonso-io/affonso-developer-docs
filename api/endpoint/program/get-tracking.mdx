---
title: "Get Tracking Settings"
api: "GET https://api.affonso.io/v1/program/tracking"
description: "Get referral tracking configuration, landing-page decoration, and postbacks"
---

Retrieve your program's referral tracking configuration, including which referral parameters are enabled, landing-page URL decoration settings, and whether postback URLs are active.

## Response

<ResponseField name="success" type="boolean">
  Always `true` for successful responses
</ResponseField>

<ResponseField name="data" type="object">
  The tracking settings object.

<Expandable title="Data Object Properties">
<ResponseField name="default_referral_parameter" type="string">
  Default referral query parameter name (e.g. `ref`)
</ResponseField>

<ResponseField name="enabled_referral_parameters" type="array">
  List of accepted referral parameter names
</ResponseField>

<ResponseField name="email_tracking_enabled" type="boolean">
  Whether referral tracking by email is enabled
</ResponseField>

<ResponseField name="name_tracking_enabled" type="boolean">
  Whether referral tracking by name is enabled
</ResponseField>

<ResponseField name="postbacks_enabled" type="boolean">
  Whether postback URLs are enabled (requires Growth plan or higher)
</ResponseField>

<ResponseField name="append_affonso_id_enabled" type="boolean">
  Whether the pixel appends the click ID as `affonso_id` to the landing-page URL.
</ResponseField>

<ResponseField name="tracking_template_enabled" type="boolean">
  Whether the pixel applies the program tracking template to the landing-page URL.
</ResponseField>

<ResponseField name="tracking_template" type="array | null">
  Ordered query-parameter template rows, or `null` when no template is stored.

<Expandable title="Tracking Template Row Properties">
<ResponseField name="key" type="string">
  Query parameter name.
</ResponseField>

<ResponseField name="value" type="string">
  Static text, a macro, or a composite value containing macros.
</ResponseField>

<ResponseField name="type" type="string">
  `literal` for static or composite values, or `macro` for one macro value.
</ResponseField>
</Expandable>
</ResponseField>
</Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.affonso.io/v1/program/tracking" \
  -H "Authorization: Bearer sk_live_your_api_key"
```
</RequestExample>

<ResponseExample>

```json Response
{
  "success": true,
  "data": {
    "default_referral_parameter": "ref",
    "enabled_referral_parameters": ["ref", "via", "aff"],

```
</ResponseExample>
