---
title: "Update Notification Setting"
api: "PATCH https://api.affonso.io/v1/program/notifications/{emailTypeId}"
description: "Update a notification setting by email type ID"
---

Update a notification setting for a specific email type. If no custom setting exists yet, it will be created. All fields are optional.

Use `campaign-submission-approved` as `emailTypeId` to enable, disable, or customize the email sent to the partner after a campaign submission is approved. Disabling it does not affect earning creation.

<Info>
The same operation is available through the [`affonso_update_email_notification`](/mcp/tools/email-notifications) MCP tool.
</Info>

## Path Parameters

<ParamField path="emailTypeId" type="string" required>
  The notification type ID to update settings for, for example `welcome`.
</ParamField>

## Body Parameters

<ParamField body="is_active" type="boolean">
  Enable or disable this notification.
</ParamField>

<ParamField body="custom_subject" type="string | null">
  Custom email subject line. Maximum 20,000 characters. Set to `null` to revert to default.
</ParamField>

<ParamField body="custom_body" type="string | null">
  Custom email body content. Maximum 20,000 characters. Set to `null` to revert to default.
</ParamField>

## Response

Returns the updated notification setting object. Same structure as items in the [List Notification Settings](/api/endpoint/program/list-notifications) response.

<RequestExample>
```bash cURL
curl -X PATCH "https://api.affonso.io/v1/program/notifications/welcome" \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "is_active": true,
    "custom_subject": "Welcome to the Acme affiliate family!"
  }'
```
</RequestExample>

<ResponseExample>
