---
title: "Create Source Event"
api: "POST https://api.affonso.io/v1/sources/{source}/events"
description: "Send source-specific webhook payloads that Affonso normalizes into its canonical event model"
---

<Info>
  Use source adapters when you want Affonso to accept an upstream payload format
  directly and normalize it for you.
</Info>

## Path Parameters

<ParamField path="source" type="string" required>
  Source adapter key. Supported values: `custom`, `segment_webhook`.
</ParamField>

## Supported Sources

### `custom`

Use the `custom` adapter when you want an endpoint-specific namespace but still
send a mostly Affonso-native payload. The adapter accepts both snake_case and
camelCase field names.

### `segment_webhook`

Use the `segment_webhook` adapter for Segment-style track payloads.

Normalization rules:

- `event: "trial_started"` becomes `event_type: "trial"`
- `event: "qualified_lead"` becomes `event_type: "lead"`
- other events become `event_type: "milestone"`
- `messageId` becomes `external_event_id`
- `timestamp` becomes `occurred_at`
- `userId` or `customerId` is used to identify the referred customer

## Request Signing

Source adapters can use a per-source secret through
`S2S_SOURCE_SIGNING_SECRETS`.

Example:

```json
{
  "segment_webhook": "secret-1",
  "custom": "secret-2"
}
```

When configured, signed requests must include:

- `X-Affonso-Timestamp`
- `X-Affonso-Signature`

Source adapters allow a 15-minute replay window.

## Response

- If the normalized event becomes a conversion, the response matches `POST /conversions`.
- Otherwise, the response matches the milestone-style result returned by `POST /events`.

## Example Request: `custom`

<RequestExample>
```bash cURL
curl -X POST "https://api.affonso.io/v1/sources/custom/events" \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "eventType": "milestone",
    "eventName": "onboarding_completed",
    "customerId": "cust_123",
    "externalEventId": "evt_onboarding_123",
    "metadata": {
      "step": "workspace_connected"
    }
  }'
```
</RequestExample>

## Example Request: `segment_webhook`

<RequestExample>
```bash cURL
curl -X POST "https://api.affonso.io/v1/sources/segment_webhook/events" \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "event": "trial_started",
    "messageId": "msg_123",
    "userId": "cust_123",
    "timestamp": "2026-05-01T00:00:00Z",
    "properties": {
      "click_id": "clk_123"
    }
  }'
```
</RequestExample>

## Example Response: Milestone Event

<ResponseExample>
```json Response
{
  "success": true,
  "data": {
    "referral_id": "ref_456def",
    "transaction_id": null,
    "event_name": "trial_started",
    "event_type": "trial",
    "external_event_id": "msg_123",
    "action": "referral_updated",
    "referral_status": "trialing"
  }
}
```
</ResponseExample>

<Warning>
  Unsupported source keys return `UNSUPPORTED_SOURCE`.
</Warning>
